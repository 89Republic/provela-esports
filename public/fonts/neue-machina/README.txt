Optional: PP Neue Machina (licensed)

The site uses Chakra Petch via next/font/google by default (no local files required).

To use licensed Neue Machina instead:
1. Add your .woff2 files to this folder (see filenames below).
2. Restore @font-face rules in app/globals.css and switch --font-sans / --font-gaming
   to 'Neue Machina', or wire them through next/font/local in app/layout.tsx.

Recommended files:
  PPNeueMachina-PlainVariable.woff2
  PPNeueMachina-PlainLight.woff2
  PPNeueMachina-PlainRegular.woff2
  PPNeueMachina-PlainMedium.woff2
  PPNeueMachina-PlainBold.woff2
  PPNeueMachina-PlainUltrabold.woff2
  PPNeueMachina-PlainBlack.woff2

Download: https://pangrampangram.com/products/neue-machina-plain
